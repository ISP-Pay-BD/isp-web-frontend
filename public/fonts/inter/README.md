# Inter — Marketing body

| | |
|---|---|
| **Rating** | 9/10 for marketing body |
| **Load** | `public/fonts/inter/inter-latin.woff2` via `src/styles/fonts/inter.css` |
| **Class** | `font-landing-body` |
| **CSS var** | `--font-landing-body` |

## Files

| File | Type |
|------|------|
| `inter-latin.woff2` | Variable (100–900) |

No npm/CDN at runtime — served from `/fonts/inter/`.

## Use on

- Marketing paragraphs, FAQ answers, footer text
- Nav links on landing (`MarketingNav`)
- Pricing feature lists, testimonial body
- Any text inside `MarketingLayout` that is NOT a headline

## Do NOT use on

- Portal screens (use Satoshi)
- Marketing hero headlines (use Plus Jakarta Sans)
