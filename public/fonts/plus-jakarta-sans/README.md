# Plus Jakarta Sans — Marketing display

| | |
|---|---|
| **Rating** | 9.5/10 for landing hero |
| **Load** | `public/fonts/plus-jakarta-sans/plus-jakarta-sans-latin.woff2` via `src/styles/fonts/plus-jakarta-sans.css` |
| **Class** | `font-landing-display` |
| **CSS var** | `--font-landing-display` |

## Files

| File | Type |
|------|------|
| `plus-jakarta-sans-latin.woff2` | Variable (200–800) |

## Use on

- Hero `<h1>`, section titles (`h2`, `h3`)
- Pricing tier names, stat counters labels
- CTA button text on marketing (optional — body font also OK)
- Plugin marketplace card titles

## Do NOT use on

- Admin/customer portal UI (use Satoshi)
- Dense table data (use Inter on marketing, Satoshi on portals)
