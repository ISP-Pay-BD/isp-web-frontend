# Satoshi — Portal UI

| | |
|---|---|
| **Rating** | 9/10 for portals |
| **CSS** | `src/styles/fonts/satoshi.css` |
| **Class** | `font-portal` (default on `<html>`) |
| **CSS var** | `--font-portal-sans` |

## Files (this folder)

| File | Weight |
|------|--------|
| `satoshi-400.woff2` | Regular |
| `satoshi-500.woff2` | Medium |
| `satoshi-700.woff2` | Bold |
| `satoshi-900.woff2` | Black |

## Use on

- `/admin/*` — dashboards, tables, sidebar, forms
- `/customer/*` — customer portal
- `/platform/*` — super-admin
- `/employee/*` — employee portal
- `/login`, `/register` — auth screens

## Do NOT use on

Marketing landing hero — use **Plus Jakarta Sans** (`font-landing-display`) instead.
