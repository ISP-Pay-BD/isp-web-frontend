## Use on

- Invoice numbers, payment TrxID
- Customer username, PPPoE ID
- IP addresses, MAC addresses
- Router config snippets, API keys (masked)
- Amount columns when tabular alignment matters

## Do NOT use on

- Regular paragraphs or headings
