# Design brief: Shared permission / system screens

1. Product and job: system tells the user they cannot proceed; job is "explain and exit"
2. Design read: calm denial screen; one message, two exits
3. References: auth DESIGN_BRIEF; Stripe permission denied; Linear empty access
4. Existing system: Satoshi, shadcn Button, ROLE_HOME redirects, destructive tint sparingly
5. Type: Satoshi; single h1
6. Color: background + muted text + one destructive icon well
7. Shape: centered composition; no cards required
8. Spacing: generous vertical, mobile-safe
9. Motion: none
10. Signature: 403 copy + Go to dashboard / Sign in
11. Conventions: keyboard-focusable CTAs; no fake KPI
12. Deliberately not doing: illustrated mascot, rainbow status, Framer
