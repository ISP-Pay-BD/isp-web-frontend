# Design brief: Auth (login / forgot)

1. Product and job: ISP staff and demos sign in; job is "authenticate and land in the right portal"
2. Design read: split auth for professional operators, language calm, leaning ISP dark brand + shadcn form
3. References: PHP/auth patterns in isppaybd_isp; Stripe login calm split; this app’s premium landing tokens
4. Existing system to honor: `#0c0118`, `#f75803`, Plus Jakarta on brand panel, Satoshi/Inter on form, AuthGuard, ROLE_HOME
5. Type: Plus Jakarta on brand panel, body 16px form
6. Color: dominant `#0c0118`, accent `#f75803` only; no second azure glow
7. Shape: rounded-xl panels/controls
8. Spacing and density: balanced
9. Motion: none on auth brand panel; form feedback via focus/disabled only
10. Signature: ISP Pay BD wordmark + one console value proposition
11. Platform conventions: redirect query param; demo user picker for mock phase
12. Deliberately not doing: dual radial glows, KPI mini-stats on brand panel, shield icon decoration stack
