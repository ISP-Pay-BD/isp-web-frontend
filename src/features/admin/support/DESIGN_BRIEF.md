# Design brief: Admin support tickets

1. Product and job: ISP admin clearing subscriber tickets; job is "triage, reply, close"
2. Design read: dense ops queue; calm language; shadcn + ISP portal
3. References: admin customers list; Linear Issues; Intercom inbox density
4. Existing system: Satoshi, DataTable, StatusBadge, PageHeader, primary `#f75803`
5. Type: Satoshi; tabular-nums sparingly
6. Color: semantic status only (open/pending/closed)
7. Shape: table-first; detail as conversation thread
8. Spacing: dense 8px rhythm
9. Motion: CSS hover only; no Framer
10. Signature: open · pending strip or facet counts near toolbar
11. Conventions: single h1; empty + error + loading shaped like table
12. Not doing: rainbow KPI tiles, staggered animate-in rows
