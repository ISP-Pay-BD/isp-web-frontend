# Design brief: Admin network ops (OLT, routers, map, diagram)

1. Product and job: NOC/admin monitoring GPON/MikroTik health
2. Design read: ops density; counts and alarms first
3. References: admin dashboard attention queue; Areas strip
4. Existing system: Satoshi, DataTable, StatusBadge, primary orange
5. Type: Satoshi; tabular-nums
6. Color: semantic online/offline only — no rainbow KPI gradients
7. Shape: summary strip + table; map markers without decorative scale spam
8. Spacing: dense
9. Motion: CSS only; no staggered animate-in KPI cards
10. Signature: OLT/ONU online·offline strip
11. Conventions: diagnostics as dialog interaction
12. Not doing: font-black KPI tiles, gradient card fills, pulse alarm noise unless real alert
