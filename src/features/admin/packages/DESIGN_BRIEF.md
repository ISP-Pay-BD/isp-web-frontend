# Design brief: Admin packages & POP packages

1. Product and job: ISP admin pricing retail/corporate plans and POP resale packages
2. Design read: catalog density; money and Mbps first; calm shadcn portal
3. References: Areas summary strip; Stripe product catalog
4. Existing system: Satoshi, PageHero, DataTable/grid, primary `#f75803`
5. Type: Satoshi; tabular-nums for ৳ and Mbps; avoid font-black
6. Color: muted + primary; semantic only for visible/hidden
7. Shape: table or interaction cards — no decorative gradient card chrome
8. Spacing: strip then toolbar/table or list
9. Motion: CSS hover only
10. Signature: plan count / active / revenue strip
11. Conventions: single h1; empty + error states
12. Not doing: rainbow KPI tiles, scale-on-hover icons, Framer
