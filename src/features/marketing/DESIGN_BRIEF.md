# Design brief: Marketing surfaces (pricing, plugins, register — inherit landing craft)

1. Product and job: ISP owners evaluating/buying ISP Pay BD; the job is "compare plans, see plugins, start registration"
2. Design read: marketing for Bangladesh ISP operators; calm exact copy; ISP landing tokens + landing craft inheritance
3. References: marketing/landing DESIGN_BRIEF + sections in this app; Stripe pricing; Linear marketing hierarchy; 21st.dev inspiration (not copy-paste)
4. Existing system to honor: `#0c0118` / `#f75803` / `#2E8BFF`, Plus Jakarta display + Inter body, MarketingNav, landing tokens in globals.css
5. Type: Plus Jakarta Sans display + Inter body, ratio ~1.333, body 16–18px
6. Color: dominant `#0c0118`, neutral white/opacity ramp, accent `#f75803` only; semantic emerald for trust checks only
7. Shape: controls 12px, containers 12–16px; pricing/plugin interaction cards OK; separation by space/tint
8. Spacing and density: 8px grid; balanced; first viewport must breathe (hero budget on promotional pages)
9. Motion: Framer OK here (200–350ms easeOut); purposeful entry only; reduced motion = static; no ambient orbs/ping
10. Signature: brand-forward first viewport + orange CTA; pricing tiers and plugin cards as the interaction signature
11. Platform conventions: keyboard-focusable CTAs; landing-specific brief overrides hero details when both apply
12. Deliberately not doing: purple glow beams, rainbow orbital timelines, floating KPI strips, MorphArrow magnetic CTA spam, shadcn light portal chrome on marketing
