# Design brief: Employee portal (salaries / advance / profile)

1. Product and job: ISP employee checking pay and advances; the job is "see what I earned / requested"
2. Design read: quiet personal finance list; same portal language as admin HR but scoped to self
3. References: admin HR summary strips; Stripe payout history
4. Existing system to honor: Satoshi, shadcn, PageHeader patterns, EmptyState, primary `#f75803`
5. Type: Satoshi; tabular-nums for amounts
6. Color: muted + semantic status only
7. Shape: summary strip + table/cards for interaction only
8. Spacing and density: dense, mobile-first
9. Motion: CSS hover only; no Framer
10. Signature: payroll totals as a strip, not icon KPI tiles
11. Platform conventions: single h1; clear empty and error states
12. Deliberately not doing: rainbow KPI grids, Framer entrances, decorative orbs
